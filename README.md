# 🏰 Hogwarts International College App

An Android e-learning application built for **Hogwarts International College**. It lets students study from home and lets teachers handle administrative work remotely.

Developed as a **Mobile Application Development (MAD)** group project (Group YORK_4) at the **Sri Lanka Institute of Information Technology (SLIIT)**, Year 2 Semester 2.

## ✨ Features

### 👩‍🎓 Students
- Secure student login
- Study from home using online course content

### 👩‍🏫 Teachers / Admin
- Secure admin login
- Manage college activities from home

## 🛠️ Tech Stack

- Java
- Android Studio
- Gradle

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kasunimakalanda/YORK-4-Android-MAD.git
   ```
2. Open the project in **Android Studio**.
3. Wait for Gradle to finish syncing.
4. Run the app on an emulator or a real Android device.
